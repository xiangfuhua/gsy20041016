"C 盘满了"应该是 Windows 用户最常遇到的问题之一。每次看到 C 盘变红，就慌着找各种清理软件，结果清完没多久又满了。其实 C 盘满了不可怕，关键是要找到"谁在占空间"，然后从根本上解决问题。

下面 3 招从浅到深，第一招快速释放空间，第二招解决根本问题，第三招防止以后反弹。

**先做一件事**：打开设置 → 系统 → 存储，查看 C 盘的空间使用情况，了解哪些大文件在占空间。这个步骤能帮你明确清理方向。

## 第一招：系统自带工具 + 磁盘清理（快速见效）

不用下载任何第三方软件，Windows 自带的磁盘清理工具就能清出不少空间。

**步骤：**
1. 打开「此电脑」，右键 C 盘 →「属性」
2. 点击「磁盘清理」按钮，系统会扫描可清理的文件
3. 勾选以下几项（可放心删除）：
   - **Windows 更新清理**（通常能清理 2-10GB）
   - **临时文件**（系统运行产生的缓存）
   - **回收站**（已删除但未彻底清除的文件）
   - **传递优化文件**（更新缓存）
4. 点击「清理系统文件」（需要管理员权限），再次勾选上面的选项
5. 点击确定，等待清理完成

> **进阶操作**：在"磁盘清理"窗口中，点击「清理系统文件」后，会多出一个"以前的 Windows 安装"选项，如果确定不需要回退到旧版本，这个可以清理掉 10-20GB。

## 第二招：转移大文件 + 修改默认路径（治本）

C 盘变红的核心原因通常是：桌面、文档、下载、微信等文件夹占用了大量空间。把这些文件夹转移到 D 盘或其他盘，C 盘的压力瞬间释放。

**① 转移个人文件夹：**
1. 打开「此电脑」，找到「桌面」「文档」「下载」等文件夹
2. 右键文件夹 →「属性」→「位置」选项卡
3. 点击「移动」，选择目标盘（如 D:\Users\你的名字\Desktop）
4. 点击「应用」→「是」，系统会自动转移文件

**② 转移微信/QQ 文件：**
微信和 QQ 的文件存储是 C 盘最大的"隐形杀手"。

- **微信**：打开微信 → 左下角菜单 → 设置 → 文件管理 → 更改目录 → 选择 D 盘
- **QQ**：打开 QQ → 左下角菜单 → 设置 → 文件管理 → 更改目录 → 选择 D 盘

**③ 清理微信缓存：**
微信设置 → 通用 → 存储空间管理 → 清理缓存（清理聊天中的图片、视频缓存，不影响聊天记录）

> **微信占空间分析**：很多人的微信缓存高达 10-30GB，特别是工作群多、经常收发文件的用户。建议每 1-2 个月清理一次微信缓存，释放大量空间。

**④ 转移虚拟内存（可选）：**
1. 右键「此电脑」→「属性」→「高级系统设置」
2. 「性能」→「设置」→「高级」→「虚拟内存」→「更改」
3. 取消勾选"自动管理"，选择 C 盘，设置"无分页文件"
4. 选择 D 盘，设置"系统管理的大小"，点击设置

## 第三招：关闭休眠 + 调整系统还原（防止反弹）

做完前面两步后，再做这两个设置，C 盘就不会轻易再爆满。

**① 关闭休眠功能（释放 3-8GB）：**
休眠文件 hiberfil.sys 占用 C 盘空间，如果不需要休眠功能（大部分台式机用户不需要），可以关掉。

以管理员身份运行命令提示符（CMD），输入以下命令：

```
powercfg -h off
```

按回车后，休眠文件会被删除。如需重新开启，把 `off` 改成 `on` 即可。

> **注意**：笔记本用户如果经常用休眠功能，请勿关闭。台式机或从不休眠的用户可以放心关闭。

**② 调整系统还原占用：**
1. 右键「此电脑」→「属性」→「系统保护」
2. 选择 C 盘 → 点击「配置」
3. 将最大使用量调整为 5%-10%（不要完全关闭，保留一定的还原点以防万一）
4. 点击「删除」清除现有的还原点（释放空间）

### 日常维护清单

| 频率 | 操作 |
|------|------|
| 每月 | 运行一次磁盘清理 |
| 每月 | 清理微信/QQ缓存 |
| 每季度 | 检查桌面、下载文件夹，清理无用文件 |
| 每半年 | 运行一次磁盘碎片整理（针对机械硬盘） |

---

C 盘清理不需要频繁操作，把默认路径改好后，C 盘空间会保持稳定。如果按照上面 3 招操作后 C 盘还是经常满，建议检查一下是不是有软件把数据存到了 C 盘（如某些设计软件的缓存、虚拟机镜像文件等），针对性地修改这些软件的存储路径即可。
