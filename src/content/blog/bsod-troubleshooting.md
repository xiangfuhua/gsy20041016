Windows 蓝屏（BSOD，Blue Screen of Death）是让很多用户最头疼的问题——屏幕突然变蓝、一堆看不懂的代码、电脑自动重启。其实蓝屏没有那么可怕，大部分蓝屏都是几个固定原因导致的，按步骤排查就能解决。

## 一、先做 3 件事：记录信息

蓝屏发生的第一时间，不要急着重启，先做好这几件事，后面排查才有方向。

**① 记录错误代码：**
蓝屏界面上会显示一个以"0x"开头的代码（如 `0x0000001A`）或一个英文关键词（如 `MEMORY_MANAGEMENT`、`PAGE_FAULT_IN_NONPAGED_AREA`）。这个代码是排查的关键线索。

**② 回忆蓝屏前做了什么：**
- 有没有安装新软件或驱动程序？
- 有没有插拔新硬件（内存条、显卡、U盘）？
- 有没有更新 Windows 系统？
- 电脑有没有异常声音、过热、异味？

**③ 检查是否频繁出现：**
偶尔一次蓝屏可能只是系统的小 bug，不需要过于担心。如果在短时间内出现多次（1 周内超过 2-3 次），就需要深入排查了。

> **小技巧**：蓝屏时电脑会自动生成一个"minidump"文件（小内存转储），保存在 `C:\Windows\Minidump` 目录下。可以用 BlueScreenView 等工具打开这个文件，查看蓝屏的具体原因。

## 二、常见错误代码对照表

以下是最常见的 5 个蓝屏错误代码及其原因：

| 错误代码 | 常见原因 | 解决方向 |
|---------|---------|---------|
| **MEMORY_MANAGEMENT** | 内存故障或驱动问题 | 检查内存条、更新驱动 |
| **PAGE_FAULT_IN_NONPAGED_AREA** | 内存问题或硬盘错误 | 检查内存、硬盘坏道 |
| **SYSTEM_SERVICE_EXCEPTION** | 驱动程序冲突 | 更新/回退驱动程序 |
| **IRQL_NOT_LESS_OR_EQUAL** | 驱动不兼容 | 卸载最近安装的驱动 |
| **CRITICAL_PROCESS_DIED** | 系统文件损坏 | 运行 SFC 扫描修复 |

## 三、逐项排查，找到罪魁祸首

### ① 先尝试重启

蓝屏发生后，首先强制关机重启。很多时候蓝屏只是系统临时性错误，重启后自动恢复。如果重启后正常且不再出现，可以不用进一步处理。

如果重启后仍然蓝屏，进入**安全模式**（开机时按 F8 或 Shift+重启）：
- 如果在安全模式下正常（不蓝屏），说明是软件或驱动问题
- 如果在安全模式下也蓝屏，说明是硬件问题

### ② 检查硬件（内存和硬盘）

硬件问题是蓝屏的主要原因之一，特别是内存条和硬盘。

**检查内存：**
1. 打开「Windows 内存诊断」工具（开始菜单搜索"内存"）
2. 选择"立即重新启动并检查问题"
3. 电脑会自动重启并运行内存测试，等待测试完成
4. 如果显示"硬件问题"，说明内存条坏了，需要更换
5. 如果有多条内存条，可以逐条拔下来测试，排除故障条

**检查硬盘：**
1. 以管理员身份打开命令提示符（CMD）
2. 输入 `chkdsk c: /f` 并按回车
3. 输入 Y，重启电脑，系统会在启动时扫描硬盘并修复错误
4. 如果发现大量坏道或修复失败，建议立即备份数据并更换硬盘

> **硬盘故障信号**：蓝屏伴随"咔咔"异响、系统响应极慢、文件突然打不开——这些很可能是硬盘损坏的前兆，请立即备份重要数据。

### ③ 检查驱动程序

驱动问题导致蓝屏非常常见，特别是显卡驱动和网卡驱动。

- **进入安全模式**：如果能进入，右键"开始"→「设备管理器」
- 检查有没有设备显示黄色感叹号，有的话右键更新驱动
- 如果是显卡驱动问题，可以卸载当前驱动，到显卡厂商官网下载最新版重新安装
- **回退驱动**：右键设备 →「属性」→「驱动程序」→「回退驱动程序」

### ④ 检查温度

电脑过热也会导致蓝屏，特别是笔记本电脑。

- 下载 HWMonitor 或 Core Temp 检查温度
- CPU 正常温度：空闲 30-50°C，满载 70-85°C
- GPU 正常温度：空闲 30-45°C，满载 65-85°C
- 如果温度超标，清灰、更换散热硅脂、使用散热底座

### ⑤ 系统文件修复

如果以上都排查过仍然找不到原因，可能是系统文件损坏了：

```
sfc /scannow    # 扫描并修复系统文件
DISM /Online /Cleanup-Image /RestoreHealth  # 修复系统映像
```

以管理员身份运行 CMD，依次执行这两条命令，等待完成后重启。

## 四、蓝屏排查流程图

**蓝屏发生 → 重启 → 正常 → 观察（可能只是偶发）**
**蓝屏发生 → 重启 → 再次蓝屏 →**
**→ 能否进安全模式？**
**→ 能 → 卸载最近安装的软件/驱动，运行 SFC 扫描**
**→ 不能 → 运行内存诊断、检查硬盘、检查温度**
**→ 仍无法解决 → 重装系统（保留文件）或送修**

---

大多数蓝屏问题都可以通过以上步骤自行解决，最常见的原因是驱动冲突和内存故障。如果按照上面的流程排查后仍然频繁蓝屏，建议备份重要数据后重装 Windows 系统，这是最彻底的解决办法。重装后如果仍然蓝屏，基本可以确定是硬件问题，需要送修检测。
